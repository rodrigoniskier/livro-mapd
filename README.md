# Mecanismos de Agressão, Patológicos e de Defesa

Página estática e responsiva com o conteúdo textual da obra de Prof. Rodrigo
Niskier Ferreira Barbosa. O projeto não utiliza bibliotecas externas: estilos,
conteúdo e interações estão reunidos no arquivo `index.html`.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub ou abra um repositório existente.
2. Envie `index.html` e `.nojekyll` para a raiz do repositório.
3. No GitHub, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, a pasta `/ (root)` e clique em **Save**.
6. Aguarde a publicação. O endereço seguirá o padrão
   `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Recursos incluídos

- layout otimizado para computador, tablet e celular;
- sumário interativo com capítulos e subseções;
- busca textual, inclusive sem acentos;
- indicador de progresso de leitura;
- ajuste do tamanho do texto;
- versão de impressão geral e botão para imprimir cada capítulo isoladamente;
- metadados de indexação e acessibilidade;
- links para aquisição da edição Kindle na Amazon.

As figuras foram omitidas. Para preservar o conteúdo verbal, informações que
estavam em tabelas foram reorganizadas em blocos de texto responsivos, sem o uso
de tabelas HTML.
